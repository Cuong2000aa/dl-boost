Cài vào Chrome / Edge

  1. Mở chrome://extensions (hoặc edge://extensions)
  2. Bật Developer mode
  3. Chọn Load unpacked → trỏ vào thư mục gốc repo PulseDM
  4. Ghim icon PulseDM → dán URL hoặc chuột phải link → “Tải bằng PulseDM”

Lưu ý: extension không thay thế 100% IDM native (hook hệ thống, lịch phức tạp). Trong trình duyệt, tăng tốc dựa trên HTTP Range + nhiều kết nối khi server hỗ trợ.
