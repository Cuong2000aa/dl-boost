PulseDM

Download manager kiểu IDM trong trình duyệt: đa kết nối, resume thật, lịch tải, grabber, batch URL và hàng đợi ưu tiên.

Xem cách cài Tính năng

Đa kết nối

Tăng tốc bằng HTTP Range, chỉnh 1–16 kết nối và giới hạn KB/s.

Resume thật

Segment lưu IndexedDB — pause rồi resume không tải lại từ đầu.

Grabber

Ctrl+Shift+Y, Alt+click, bắt download Chrome theo phần mở rộng.

Lịch & batch

Hẹn giờ từng file, dán hàng loạt URL, ưu tiên hàng đợi.

Cài vào Chrome / Edge

  1. Mở chrome://extensions (hoặc edge://extensions)
  2. Bật Developer mode
  3. Chọn Load unpacked → thư mục gốc PulseDM
  4. Reload sau mỗi lần cập nhật code

Preview này chỉ demo giao diện. Để tải file thật, cần load unpacked extension.
